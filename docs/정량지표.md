# 정량지표 — 무엇을 어떻게 재는가

> 프로젝트 목표 3종을 실제 수치로 내는 방법과, 그 수치를 어디까지 믿을 수
> 있는지를 적는다. 계수기는 [`common/metrics.py`](../common/metrics.py),
> 측정 도구는 [`tools/measure_metrics.py`](../tools/measure_metrics.py)다.

| 지표             | 목표     | 무엇을 세는가                            |
| -------------- | ------ | ---------------------------------- |
| **비인가 패킷 수용**  | 0회     | ROC가 아닌 국의 명령을 **본선이 그대로 따른** 횟수   |
| **인증 성공률**     | 99% 이상 | **정당한** 자격증명이 검증을 통과한 비율           |
| **성능 저하**      | 30% 이하 | 보안 판정을 켰을 때 명령 왕복 지연이 늘어난 비율       |

---

## 1. 바로 재는 법

```bash
python tools/measure_metrics.py
```

한 번 돌리면 세 지표가 모두 나오고 `results/metrics_*.json`에 남는다.
셋 다 통과하면 종료 코드 0이다.

```
  지표                              측정값          목표  판정
  ----------------------------------------------------------
  비인가 패킷 수용                      0회          0회  통과
  인증 성공률                      100.00%     99% 이상  통과
  성능 저하                           +1.4%     30% 이하  통과

  비인가: 제시 110건 중 수용 0건 (송신국 10건 · 위조 자격증명 100건)
  인증: 정당한 자격증명 100/100건 통과
  검증 비용: 1건당 중앙값 136 µs (200건)
  지연: 기준 중앙값 505 µs (25건) → 보안 적용 500 µs (25건)

  방어 전(판정 끔): 비인가 10건 중 10건 수용 — 이것이 막으려는 피해다
```

위는 `--cycles 25 --intruders 10 --certificates 100`으로 실 ECDSA 백엔드에서
잰 값이다. 기본값(20/10/10)은 인증 표본이 적으니 보고용 수치는 이 정도로 올려 잰다.

실 VDE-TER 무선을 태우려면 (cryptography 설치된 파이썬 필요):

```bash
python tools/measure_metrics.py --transport software --cycles 12
```

콘솔 GUI에서도 같은 계수기가 돈다. ROC 창 **정량지표** 패널에 실시간으로
뜨고, `로그 저장`을 누르면 `results/console_*.json`의 `metrics`에 함께 남는다.

## 2. 세는 규칙 — 틀리기 쉬운 두 곳

### 위조를 거부한 것은 인증 실패가 아니다

위조 인증서를 거부한 것을 인증 실패로 세면 **방어가 잘 될수록 인증 성공률이
떨어지는** 거꾸로 된 수치가 나온다. 그래서 분모를 나눈다.

    정당한 자격증명   → 인증 성공률의 분모·분자
    위조 자격증명     → 비인가 쪽에서 센다. 통과하면 그때가 비인가 수용이다

### 거절 ACK를 돌려준 것은 수용이 아니다

본선은 거절할 때도 응용 ACK를 돌려준다(S-421 status=ERRORS). 응답을 냈는지로
세면 거절이 수용으로 잡힌다. 기준은 **배가 그 명령대로 움직였는가**다
(`MassAgent._handle_route`에서 `decision.accept or decision.cancel`).

## 3. 판정 근거와 방어를 분리한다

지표가 성립하려면 "누가 정당한 송신국인가"라는 **사실**과 "본선이 그것을
판정하는가"라는 **구현**이 따로 있어야 한다.

| 무엇                          | 어디                          | 하는 일                |
| --------------------------- | --------------------------- | ------------------- |
| `Metrics.expected_senders`  | 계수기                         | 정당한 국이 누구인지 아는 것    |
| `MassAgent.authority_policy` | 행위자                         | 실제로 거절하는 것 (기본값 없음) |

둘이 분리돼 있어서 **판정을 끈 상태에서 비인가 명령이 몇 건 먹혔는지**를 셀 수
있다. VDE-TER에 송신자 인증이 없다는 것이 이 프로젝트의 연구 대상이고, 그 부재를
수치로 보이는 것이 이 지표의 목적이다.

`measure_metrics.py`는 그래서 **판정을 끈 채 한 번, 켠 채 한 번** 공격을 넣는다.

```
방어 전(판정 끔): 비인가 8건 중 8건 수용   ← 막으려는 피해
방어 후(판정 켬): 비인가 8건 중 0건 수용   ← 지표
```

콘솔에서는 `--authority strict`로 판정을 켠다. 기본값은 `open`(판정 없음)이며,
이것이 표준의 현재 상태를 그대로 재현한 쪽이다.

```bash
python apps/console_server.py --authority strict
```

## 4. 성능 저하를 재는 방법

### 구간을 몰아서 재면 안 된다

실행이 길어질수록 로그·항적·명령 이력이 쌓여 스냅샷 직렬화가 무거워진다.
두 구간을 순서대로 재면 **나중에 잰 쪽이 무조건 느리게** 나온다 — 보안 비용이
아니라 측정 순서가 만든 차이다. 처음에 그렇게 재서 +45%가 나왔다.

그래서 한 회마다 판정을 껐다 켜며 **번갈아** 재고, 회마다 순서도 뒤집는다.
그렇게 하면 같은 조건에서 +1.6%가 나온다.

### 잡음 바닥

두 구간을 똑같이 두고(판정을 끈 채 이름표만 바꿔) 20회씩 재면 **±1.5%**가
나온다. 이것이 이 측정의 분해능이며, 그보다 작은 차이는 읽지 않는다.

### 어느 경로로 재는가

| 경로                   | 왕복      | 무엇을 보는가                                 |
| -------------------- | ------- | --------------------------------------- |
| `--transport direct` | ~0.5 ms | **응용 처리 비용**이 그대로 드러난다. 지표는 이쪽으로 읽는다    |
| `--transport software` (구 vdeter) | ~8 s    | 대부분이 프레임 배정 대기라 보안 비용이 지터에 묻힌다. 무선에서도 지표가 성립하는지 확인하는 용도 |

## 5. 이 수치의 한계 — 반드시 함께 읽을 것

### 성능 저하는 하한이다

현재 명령 경로의 보안 절차는 **송신국 판정 하나**다. 메시지별 서명 검증은
아직 없다 — SC-VDE 형식은 서명 없는 Segment Type 0이기 때문이다
([전선형식_노선_SC-VDE-005.md](전선형식_노선_SC-VDE-005.md)). 그래서 측정된
+1.6%는 **하한**이며, 메시지별 서명이 들어가면 이 값이 커진다.

암호 연산의 실제 비용은 인증서 검증 시간이 따로 보여 준다 (실 ECDSA P-256
기준 **1건당 130~170 µs**, 200회 표본).

### 인증 성공률은 표본이 적다

콘솔에서 발급한 인증서 몇 건으로는 99%를 의미 있게 말할 수 없다. `--certificates`
값을 충분히 올려야 한다(100건이면 1건 실패까지 목표를 만족한다).

### 백엔드에 따라 검증 비용이 다르다

`cryptography`가 없으면 대체 HMAC 백엔드로 돌아가며, 그때 검증 비용은 실제
ECDSA 값이 아니다(**24 µs** vs **136 µs**). 도구가 이 경우 경고를 함께 낸다.
보고용 수치는 cryptography 설치된 파이썬으로 잰다.

## 6. 어디에 붙어 있나

| 파일                              | 하는 일                                     |
| ------------------------------- | ---------------------------------------- |
| `common/metrics.py`             | 계수기·판정·요약 출력                             |
| `MASS/mass_agent.py`            | `metrics=`를 받아 명령 수용/거절을 센다              |

| `tools/measure_metrics.py`      | 헤드리스 측정 — 세 지표를 한 번에 낸다                  |
| `tests/test_metrics.py`         | 세는 규칙 검증 (특히 §2의 두 함정)                   |
